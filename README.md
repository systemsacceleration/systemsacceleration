# Hey, we're Systems Acceleration 👋

We build simple AI systems that save you hours, and we share how we do it so you can use them too. No tech background needed.

## ⚡ Free tools

| Tool | What it does |
|---|---|
| [**YouTube Watch for Claude**](https://github.com/systemsacceleration/youtube-watch) | Paste a YouTube link into Claude and get the full transcript, a summary, notes or a Google Doc. No API keys, nothing to install. |

**Install in one step:** open the Claude desktop app, go to the **Code** tab, and paste:

```text
Install the youtube-watch skill from https://github.com/systemsacceleration/youtube-watch
```
